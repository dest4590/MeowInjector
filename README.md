A kernel-level DLL injector for Windows. Manual maps DLLs into target processes using a mapped driver (kdmapper)

## Usage

1. Run the injector.
2. Click **MAP** if the driver status shows "unloaded".
3. Pick a process from the dropdown.
4. Browse for a DLL.
5. Click **INJECT**.
